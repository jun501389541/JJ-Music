## 调试报错说明

用户截图的 `0x271D` 对应 Winsock 10013（WSAEACCES），Chromium 调试 HTTP 服务未能绑定端口。现场检查显示固定端口 9223 被进程 54916 绑定，且不在 IPv4 排除端口范围内；未终止该进程。

将原调试命令中的固定端口改为自动分配：

```powershell
$env:JJ_DEBUG_PORT = '0'
npm run dev
```

保留已有隔离数据目录环境变量。终端会输出实际的 `DevTools listening on ...` 地址。这项错误影响远程调试服务，不直接说明音源导入或播放器失败。

微软错误码说明：[Windows Sockets error codes](https://learn.microsoft.com/en-us/windows/win32/winsock/windows-sockets-error-codes-2)。
