# A3：目录与音源解耦

> 2026-10-08 用户修订：目录资料默认可用，取消目录授权弹窗和开关。下文授权相关描述为原始计划/实施记录，现由 [目录策略修订](../2026-10-08-online-catalog-default.md) 取代；在线播放仍需可用音源。

- 状态：实现与自动化检查完成；待 G-A 作者试听验收。
- 基线：`main`，起始提交 `cf420570bdf78930587435cd5bbe322e991e6bc9`；承接 A1、A2 工作区改动。
- 上游规则与验收：SRC-02；V03、V23；D-A-5。

## 实际改动

- `OnlinePlatformRegistry.platforms(capability)` 按显式 `onlineCatalogConsent` 与静态应用适配器能力返回目录平台，不再要求对应 LX 音源启用；`eligiblePlatforms()` 继续表示可用于播放/提示的活跃音源能力。
- 搜索、热词、歌单导入及资料路由沿用注册表的实时 consent 检查。未同意时不开放适配器；旧 `allowBuiltinOnlineSearch` 字段不会授权网络。
- 搜索界面在撤销同意时使搜索代次失效、取消在途搜索、清空在线结果与热词并重置不可用的平台页签；已保存在线歌曲和歌单不删除。
- 搜索及歌单导入界面的无服务说明指向在线目录设置，不再要求用户导入播放音源。

## 自动检查

- 注册表：授权关闭无能力；授权开启时零 LX 音源也提供静态目录能力；停用音源不会撤销目录能力。
- 路由：搜索、热词和歌单导入覆盖零音源、单一音源、授权撤销与平台能力矩阵。
- UI/门禁：`search-view-playback` 3 项通过；`npm run check:gate` 5/5；整体 `npm run verify` 56/56；类型检查和生产构建通过。

## 兼容与交接

已保存在线条目和歌单继续保留。目录同意关闭时在线搜索结果不显示；在线播放仍须有适配的音源解析能力。G-A 需试听并确认关闭/重新开启授权时搜索、热词和已保存列表状态符合预期。
