# OR8 生产桌面应用的快速切歌与音源停用

沿用已授权的 HYW 源和网易云/QQ 原固定样本，以全新 profile 运行生产 Electron/Vue/preload/源宿主和媒体引擎。使用仓库原生 CDP 测试方式；目标是桌面应用而不是 Browser 插件标签页。只检查自动化集成，不代替作者日常操作或听感验收。

- [x] 构建当前应用，核对 HYW 摘要；建立静音、空资料 profile，确认数据目录正确。
- [x] 通过正式 IPC 导入和启用 HYW；以生产 player store 初始化两项队列，等待真实播放时钟推进。
- [x] 连续点击实际下一首/上一首控件，核对最终原条目、解析条目与播放时钟；通过生产队列移动动作核对当前条目不随索引错位。
- [x] 在源管理页面点击实际停用开关，随后切到另一条目，确认无有效源时不能沿用旧地址新播；观察协议请求状态，但不把已完全缓冲时的状态当作活动连接中止证据。
- [x] 保存截图与脱敏状态，检查异常、源哈希、进程/profile 清理，更新 OR8 记录并索引。

测试边界：仅在测试进程注册 IPC 时将自动 sources:verify-platform 抽测返回明确 unknown 并计数，避免它额外抽测第三个平台。该替换不用于 musicUrl、source toggle、媒体协议或播放器；其他实际路径照常执行。队列重排通过生产动作验证，不宣称拖拽交互通过。不使用日常资料，不改原脚本，不安装发布或提交推送。

Ruling: 撤销按应用上游 reader 的取消/Abort 证据判断，不要求 Chromium webRequest 登记立即消失，也不把已缓冲音频继续播放判为当前规范下的泄漏。设计 6.5/8.1 要求源版本失效和在途隔离，没有规定停用后立即静音。错误成本：若作者期望停用后立即无声，现有交互不满足，需另行明确播放器行为并补回归。
