# 普通歌单批量改名

2026-10-25。状态：实现与本轮自动验收完成。设计已获用户批准，范围为普通歌单添加前后缀、逐字查找替换；不含序号、收藏或默认歌单。

## 实现

- 批量管理新增“复制与合并 / 批量改名”工具切换；仍只允许普通歌单。预览按当前可见顺序逐行展示旧名和新名，并显示变化/不变数量。
- 前后缀与替换是互斥模式。替换区分大小写、替换所有字面匹配；`$&` 等保持普通文本。空查找、空白结果、NUL、超长名称或过大候选会整批拒绝；每个输出长度在分配字符串前计算。
- 主进程有独立的预览租约、取消代次和10分钟token。确认后只接受一次；保存前逐项确认来源歌单仍存在且名称与预览一致。曲目、封面、平台来源、位置等并发变化保留。
- `PlaylistStore` 在已有写队列内获取名称快照，批量更新只改名称字段；一次原子持久化，失败整批回滚。资料迁移、退出和本地重新定位维护锁会使预览租约失效。
- strict IPC/preload 不接受渲染层提交最终名称或歌单/曲目对象。确认不会变更歌单ID、内容、收藏、侧栏顺序或播放队列。
