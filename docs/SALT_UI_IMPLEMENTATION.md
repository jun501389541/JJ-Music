# Salt 风格界面与在线音乐整合

本轮在原有 Electron / Vue 项目中独立实现界面，保留 JJ Music 名称与在线音乐能力。参考 `source/Salt Player for Windows` 的静态资源、菜单文字及已有研究资料。未将 Salt 二进制、图标包或原生音频引擎复制进发布包。

## 发现音乐与播放页更新

- 保留“发现音乐”侧栏入口，并恢复为启动首页。“最近添加”改为真正的“最近播放”：本地和在线歌曲实际开始播放后记录，按最近播放顺序去重，保存最多 100 首，首页展示最近 50 首；失败和仅预加载的歌曲不会计入。历史保存在应用设置中，重启后保留。
- 搜索默认覆盖本地曲库与全部在线平台。本地按标题、艺术家、专辑匹配，优先显示精确标题；本地结果立即展示并明确标注，在线结果随后追加。可切换“本地音乐”或指定在线平台，在线故障不会隐藏本地结果。Ctrl + F 进入全局搜索。
- EQ 控件移入播放页，点击“EQ 均衡器”展开侧栏，预设及十段调节即时生效、自动保存。原设置入口跳转到播放页 EQ，不再保留两套编辑界面。
- 播放页新增“播放列表”按钮及歌曲数量，展开当前队列侧栏，支持双击切歌、当前歌曲高亮、右键移除。按 Esc 或关闭按钮收起侧栏。
- 本次新增历史与本地搜索回归，离线测试扩为 11 组；界面脚本更新为上述新流程，并在测试后恢复用户设置及播放历史。新截图为 `09-discovery-history.png` 至 `13-small-playback-list.png`。

## 在线音乐流程

沿用项目已有的 LX 兼容音源宿主和平台搜索实现：

1. 按平台搜索或聚合搜索歌曲；搜索不依赖导入播放音源。
2. 播放时使用已启用音源解析地址，支持 `128k → 320k → flac → flac24bit` 四档偏好；失败只向低音质降级。
3. 启用本地优先时，只有曲名、艺术家一致且已知时长相差不超过 5 秒的文件可替代在线音频。保留 Live、Remix 等版本后缀。
4. 原平台失败后，按同一录音条件尝试可用备用平台；保留原来的地址缓存过期、失败重试上限和防止旧请求覆盖新播放的处理。
5. 本地与在线歌曲共用队列、收藏、歌单和歌词显示。搜索结果增加请求代次校验，避免快速换平台时旧结果覆盖新结果。

在线可播范围仍取决于用户导入并启用的音源及其服务状态，并非复制 LX 的全部客户端功能。

## 明确的能力边界

- 这是 Salt 风格的独立实现，不是完整功能或像素级一比一移植。自动审批拒绝运行第三方 Salt 可执行文件，因此本轮没有实测原程序的动态界面。
- 当前使用 Web Audio 系统共享输出；没有 WASAPI 独占、ASIO、DSD 直通、自动切换设备采样率、无间隙播放或 Salt 的 BASS 引擎。设置中以能力说明展示，没有无效开关。
- 云母/亚克力调用 Electron 窗口材质接口，实际效果依赖 Windows 版本；较旧系统可能不显示材质效果。
- 显示缩放范围为 85%–125%；快捷键在应用内生效，没有注册全局系统快捷键。
- 尚未实现桌面悬浮歌词、原版全部音效、下载管理、账号/歌单云同步等扩展功能。

## 验证与复现

2026-09-17 验证结果：类型检查/生产构建通过，离线测试 10/10 组通过，完整播放 E2E 30/30 项通过，界面检查 23/23 项通过。已核对歌曲、外观、歌词设置、均衡器、多级菜单、播放页和 940×620 小窗口截图。

- `npm run verify`：类型检查、构建及 10 组离线测试。
- 新增回归：列表循环与顺序末尾行为、插播队列去重/顺序、本地优先严格匹配及关闭偏好。
- `npm run test:e2e`：真实 Electron / IPC / 音频解码、频谱、切歌与故障路径；结束后恢复生产构建并确认测试入口不可达。
- `node tools/probe/salt-ui-smoke.mjs`：实际界面路由、虚拟行数量、主题保存、二级菜单、音频进度、播放页偏好；暂时修改设置后恢复。使用当前用户音乐库，需已有至少一首可播放文件。
- 界面截图保存在 `docs/research/screenshots/salt-ui/`。
- `npm run dist`：生成 `release/win-unpacked/JJ Music.exe` 及 NSIS 安装程序。

原代码备份位于 `.cache/pre-salt-ui.zip`。实现重点入口为 `App.vue`、`stores/ui.ts`、`utils/settings-pages.ts`、`utils/track-actions.ts` 以及新的 `ContextMenu`、`DialogHost` 和虚拟 `TrackList` 组件。
