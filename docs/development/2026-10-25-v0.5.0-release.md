## 保留的验收边界

- 本轮使用离线生成音频和隔离合成资料，没有读取个人曲库或第三方音源脚本。
- 真实平台曲目/音质可用性、既有失败解码样本及真实音源更新/回退仍按各自记录单独验收；本轮发布验收没有将其改记为通过。
- 人工听感仍待验。安装验收运行在可丢弃的 GitHub Windows runner，便携验收使用自有临时资料，不代表日常资料在所有环境下均已人工验收。
- `.graphflow`、`.cache`、凭据、私钥、音源脚本和个人音乐不在提交或发行包中。
