# OR8 固定真实样本的完整内存解码

目的：沿用用户此前对指定目录音源与自选样本的授权，为 HYW 源的网易云、QQ 各一个既有样本补充完整传输与解码证据。复用现有 SourceEngine auto、受限宿主和公开 URL/DNS 守卫，不修改生产功能。

- [x] 核对原有静态准入、脚本摘要及两平台固定样本时长（各 04:16）。
- [x] 构建生产测试模块；在获批宿主中每平台只尝试一次。初始化与解析共享 60 秒，媒体传输和解码共用 120 秒、32 MiB 上限。FFmpeg 无 -t 截断参数，使用严格错误处理、音频首轨和 null 输出，不写音频文件。
- [x] 通过条件同时要求：传输自然 EOF、已知 Content-Length 匹配、解码器退出 0 且无错误级诊断、progress=end、解码时长与目录时长相差不超过 2 秒。缺失时长不报完整成功；上游失败保持失败，不换源或样本制造成功。
- [x] 关闭 reader/解码器/源宿主，校验临时目录位于专用缓存内再清理，复核原始脚本摘要，写脱敏报告与 OR8 交接。

边界：此结果只涉及一个源两平台的固定样本，不证明录音身份、实际码率、无损真实性、主观听感、产品 UI 日常交互或安装升级。既有 24 项短播和其他历史失败记录不重跑、不覆盖。日常资料保持原状；不提交、推送或发布。
