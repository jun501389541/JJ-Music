# 导航数量与平台验证

侧栏显示歌曲、曲风、专辑、艺术家、文件夹分组、音乐库目录、已导入音源、歌单及播放队列的数量，空集合显示 0。数据变化时自动更新。

启动、启用、重载音源后，平台卡片右上角自动显示验证状态；也可点击“重新验证平台”。悬停状态可查看原因、测试歌曲和检测时间。

- 验证中：等待或正在检测。
- 抽测通过：在同一平台解析测试歌曲地址并读取到可识别的音频数据。
- 验证失败：本次测试歌曲解析或音频请求失败。
- 未能验证：搜索不可用、超时或格式无法识别，不能据此判定音源失效。

每个平台最多测试两首歌曲，不使用跨平台兜底。限制同时验证两个平台，每个平台最长 20 秒；请求少量音频数据后关闭流。结果仅代表本次样本，不保证所有歌曲可播，也不代表每个已导入脚本都通过。

验证：类型检查、生产构建、13 个离线测试套件通过；Electron 界面检查通过，覆盖数量显示、自动验证收敛及手动重试。独立配置副本避免修改运行中播放器的数据。

本次联网样本结果：网易云、QQ、酷狗、酷我通过；咪咕因测试搜索不可用显示“未能验证”。网络和音源状态会变化，以软件本次结果为准。

旧版运行中时，可用 `node tools/package.mjs --output=release/platform-status` 在独立目录生成新版，避免覆盖使用中的程序。
