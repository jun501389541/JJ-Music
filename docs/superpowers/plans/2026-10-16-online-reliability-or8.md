# OR8 授权真实音源逐项检查计划

**Goal:** 根据用户追加指令“每个音源都试试吧，你自定义来测试就行”，检查指定目录21份脚本，仍区分初始化、真实目录、地址解析、媒体和听感。
**Architecture:** 复用 OR7 显式检查工具，先静态准入和哈希记录，再用现有平台目录各一次查询选实际曲目；逐源串行、各运行60秒总预算、独立临时资料。目录报告与每份源报告分别持久化。
**Spec:** ../specs/2026-10-15-online-reliability-design.md，OR8。用户新的全部脚本授权扩大了前一轮单脚本范围；每份仍只用每平台一个固定样本，不以不断换曲重试制造成功。

- [x] 保存21份原始哈希并执行现有静态校验；被拒绝者仅记录，不绕过或改写。
- [x] 网易云、QQ各查询一次自选关键词，保存当前实际返回的歌曲样本，查不到时明确未测试，不编造ID。
- [x] 逐源执行初始化、所选平台单样本地址解析；并发1，各源至多60秒，共用该源预算、取消和清理。
- [x] 对解析成功项补充同曲音频首字节检查：只在内存取当前地址，受控Range最多保留1024字节并取消，不下载整曲、不播放、不当作听感；分开记录再次解析与媒体格式头结果。
- [x] 不改变日常profile/文件，不把地址成功当媒体播放；原始脚本和曲名/URL不进入可分享报告。
- [x] 复核21份原始哈希和临时资料回收，更新OR8结果。人工听感、实际应用日常操作和安装/发布保留待验收。

本阶段仅验证操作，不新增产品功能，不重复运行没有变化的全量离线检查。
