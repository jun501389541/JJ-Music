# OR8：待写入侧车失败与重试的生产界面验收

2026-10-17，补充 RR08、RR16 的受控文件写入故障证据，接续[候选歌词回读与确认写入](OR8-pending-write-ui.md)。本轮仅扩展探针，不修改产品行为。

## 方法

复用 tools/probe/pending-assets-ui.mjs 的独立生产构建、生成 WAV/歌词和自有临时 profile。真实候选入口暂存歌词、清缓存并确认可回读之后，在该运行的 fixture-local.lrc 输出路径创建空目录，令真实原子写入的 rename 失败。不更改权限、磁盘配额或用户文件，也不注入假 IPC 返回值。

点击生产设置页“全部写入”，检查该输出路径的错误 toast；待写入选择仍在服务中，队列 JSON 字节完全不变，WAV 字节完全不变，冲突目录未被覆盖，临时输出文件清理完毕，页面保留1项且可继续操作。随后仅通过非递归 rmdir 删除探针自己创建的空目录，重新点击同一按钮，沿用真实 LRC 内容、队列落盘清空、音频不变和 sidecar 本地解析检查。目录若意外非空则操作失败并保留现场，不扩大删除范围。
