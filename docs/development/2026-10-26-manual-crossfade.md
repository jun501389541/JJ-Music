# 当前队列手动交叉渐变开发与验收

日期：2026-10-26。状态：实现、独立审查修复与自动验证已完成；未提交、未合并、未推送。

依据[设计](../superpowers/specs/2026-10-26-manual-crossfade-design.md)与[实施计划](../superpowers/plans/2026-10-26-manual-crossfade.md)。

## 交付行为

设置中新增独立的手动切歌交叉渐变，默认 0 关闭，0–12 秒、1 秒步进。当前队列下一首、真正上一曲和筛选后点选通过显式 `playQueueEntry` 边界接入双通道。新歌单、历史队列恢复、内部重试继续走原播放流程。

新曲准备时保持旧曲播放及界面状态，显示准备目标；有效播放时提交身份、歌词和一次播放记录。完成前失败恢复旧曲实时状态，错误单独通知。短曲与未知时长准备后通过零时长交接；引擎保证 started 先于 completed 清理。

支持连续导航、上一首撤回、随机未播放抽取归还、自动预载复用、请求替换与生命周期取消。自动和手动共用至多一个备用通道；渐变中再次切歌先完成当前交接，再准备新目标。
