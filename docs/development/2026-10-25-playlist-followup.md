## QQ 搜索仍未接通

沿用 F2 已批准的公开接口、游客公共参数与关键词“轻音乐”，只向 `u.y.qq.com/cgi-bin/musicu.fcg` 发出 GET、POST 各一次。每次12秒、2MiB上限，无登录、Cookie、签名计算、官网脚本执行或第三方音源。两个请求均 HTTP200、顶层及业务 code0，但 `is_filter=-2`、`sum=0`、列表空，估算数量分别180、600。本轮没有获得可用匿名响应契约，不能将过滤响应当作合法零结果，也不能把能力标成已接通。

原始响应和摘要保存在忽略目录 `.cache/qq-playlist-20261025/`。不继续盲试参数，不扩大到账号或签名方案。QQ链接/ID导入仍沿用现有入口。

## 更正原待办判断

“酷狗、酷我、咪咕尚未支持已保存歌单差异刷新”是基于 README 限定表述得出的错误判断。实际 `PlaylistDetailView.vue` 对所有带来源ID的在线歌单显示刷新面板；`PlaylistRefreshService` → `LibraryRouter.readSnapshot` → `importPlaylist` 已覆盖五平台，没有仅限网易云/QQ的门禁。因此本轮补验证和文档，不重新实现已存在功能。

规则保持：只在用户点击后读取；先预览新增、移出及排序，再确认应用；不完整、失败或旧缓存不可应用；保留本地歌单名称、保留条目的资料和播放队列，不删除音频。来源已丢失的本地副本不产生远程刷新能力。
