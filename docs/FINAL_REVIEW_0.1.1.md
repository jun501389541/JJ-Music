# JJ Music 0.1.1 终版审阅记录

审阅范围：主进程与 IPC、媒体访问、音源及平台验证、播放与歌词、曲库与歌单持久化、搜索与主要页面、在线下载、公开歌单导入、构建与 Windows 分发配置。

## 本轮修复

1. 下载不再要求目标磁盘支持硬链接。NTFS 仍可使用硬链接；不支持时使用排他复制，保留同名文件不覆盖的约束。
2. 修正 MPEG-4 / M4A 与 ADTS 容器识别，避免保存成错误的 MP3 扩展名。
3. 退出时停止下载调度、终止等待中的解析、清理下载临时文件，并等待任务记录及 JSON 写入结束。重试时清除旧输出路径。
4. 修正复制提交阶段的取消竞态；取消后不会遗留一份被误标为取消的已发布文件。
5. 同一搜索页面通过“在线搜索”等入口切换关键词时，刷新输入框和结果。
6. 移除 OGG / OGA 标签写入的错误能力声明；备份失败时拒绝修改原音频，拒绝写入元数据链不完整的 FLAC。
7. 封面与歌单响应在读取过程中执行大小限制，封面超时覆盖完整响应体，避免无限读取；导入中跳过单条无效歌曲并显示提示。
8. 下载记录兼容 UTF-8 BOM，重启恢复时不再简单丢弃超出 500 条的记录尾部。
9. 打包前清除 VITE_E2E，避免继承测试环境；实际包运行时确认测试钩子不可访问。
10. 版本提升至 0.1.1，标题栏和关于页面从构建时的 package.json 读取版本；输出分别命名的 Setup EXE 和 Portable ZIP。

## 验证结果

- 类型检查、生产构建、14 / 14 离线测试套件通过。
- 播放端到端：30 通过，0 失败；随后恢复干净生产构建并验证无可访问测试钩子。
- 运行实际 `release/final-0.1.1/win-unpacked/JJ Music.exe`：40 项检查通过，包括版本、导航数量、搜索刷新、真实音频推进、EQ、队列、设置保存、音源状态、歌单导入、实际 128k 下载及正常退出。
- 测试使用独立配置副本，没有覆盖用户正在运行的旧版目录。
- 包内 34 个应用构建文件与当前 out 逐字节一致，包内版本为 0.1.1。
- Portable ZIP 的 75 个文件完整性检查通过。安装 EXE 内嵌压缩数据检查通过；7-Zip 提示压缩数据之后还有安装器尾部数据，检查结果仍为 Everything is Ok。
- 已生成 SHA256SUMS.txt。

## 结论与已知边界

本轮审阅与验证没有发现阻塞当前版本发布的问题。这是当前功能范围的终版构建，不代表可以证明软件在所有环境中没有缺陷。

在线音源和公开歌单依赖外部服务，可能受网络、权限或平台接口变化影响。下载目前从头重试，不支持断点续传；嵌入歌词和封面支持 MP3 / FLAC，其他格式显示限制提示。翻译与罗马音按平台返回内容保存。免安装版在完整解压后运行，默认与安装版共用用户配置；不是将所有用户数据写入 ZIP 所在目录。

已验证安装器构建和内部数据、同版本程序实际运行；未在用户当前环境执行安装或卸载流程，以免改变其已安装版本与快捷方式。
