## 生产缺陷与修复

队列已经落盘并在启动时载入，但 lyricResolve 只读歌词解析缓存和本地文件，不取回队列中的歌词。正常关闭再启动后，设置页仍显示1项待写入，禁网回读却为空。内存缓存中的 pending 标记不能代替持久化资料。

主进程现按权威曲库条目的 id 与 path 选取待写入歌词，传给 resolveLocalLyric。优先级保持同目录 LRC、当前内嵌歌词、持久化待写入选择、普通缓存/网络；用户保存的选择不冒充当前适配器的自动缓存。当前进程同文本选择附带的翻译仍保留。队列读取异常不阻断本地歌词，损坏反馈仍由设置页提供。

恢复结果不写入解析缓存；stageFetchedLyric 遇到 pending 结果直接返回，不在只读回读时重写队列或刷新选择版本，也不将并发丢弃后的旧快照重新加入队列。
