# 在线下载与歌单导入

## 使用

- 在线歌曲右键 → 下载歌曲 → 选择音质。多选时按所有选中平台共同支持的音质批量下载。
- 侧栏“下载管理”查看进度、失败原因、标签写入提示，取消任务、重试或打开文件位置。
- 设置 → 下载：选择下载目录；开启或关闭 LRC 保存、嵌入歌词、翻译、罗马音、封面。默认目录是系统下载目录下的 JJ Music。
- 侧栏“导入歌单”：选择网易云、QQ、酷狗或酷我，粘贴公开歌单网页版链接或数字 ID，读取预览后导入为新歌单。保存为本地快照，保留来源，不自动同步或下载音频。

## 行为与边界

下载只请求所选音质，不使用播放时的降质逻辑。检查真实音频格式，拒绝错误页面、有损冒充无损以及不足 24 bit 的 Hi-Res 响应。音质仍依赖音源真实提供的内容，无法检测上游是否曾进行有损转码。

MP3 使用 ID3，FLAC 使用 Vorbis 注释和 PICTURE 块。原文、翻译和罗马音按时间合并为多行 LRC 并写入歌词标签；本地播放保留同一时间的多行文本。其他可识别格式保留原始音频，提示嵌入限制并为歌词提供 LRC 回退。歌词和封面缺失不导致音频下载失败。当前内置歌词查询覆盖网易云、QQ、酷我；翻译和罗马音以接口实际返回为准。

下载流式写入临时文件，同时运行两个任务；同名文件自动增加序号，不覆盖原文件。每批最多 500 首，单文件最大 1 GB，任务最长 15 分钟。保留最近 500 个结束任务；退出时未完成的任务下次显示失败，可从头重试。目前不支持断点续传。

公开歌单每次最多读取 5000 首；缺失、访问限制和读取数量差异会显示在导入预览中。网易云按返回的歌曲 ID 补齐详情并保留顺序；酷我和酷狗按页读取。暂不支持登录后私密歌单、酷狗口令以及任意短链接，使用网页版完整链接或 ID。

## 验证

- 类型检查、生产构建与 14 个离线测试套件通过。
- 新增测试覆盖 MP3 / FLAC 歌词及封面回读、音频数据保留、多语言歌词、同名保护、取消、无效响应、严格音质、持久化、歌单分页与缺失提示。
- 独立 Electron 配置副本中完成 36 项界面检查，包含下载设置、导入预览、保存歌单、右键音质菜单和实际下载。
- 实际下载 128k MP3，回读码率 128000、歌曲和歌手标签、1 份嵌入歌词、1 张 JPEG 封面，LRC 已保存，无警告。
- 公开歌单联网样本：网易云 200 / 200、QQ 30 / 30、酷我 32 / 32、酷狗 15 / 15。接口状态会变化，以使用时结果为准。

适配时核对了 [LX 网易云歌单接口](https://github.com/lyswhut/lx-music-desktop/blob/master/src/renderer/utils/musicSdk/wy/songList.js)、[QQ 歌单接口](https://github.com/lyswhut/lx-music-desktop/blob/master/src/renderer/utils/musicSdk/tx/songList.js)、[酷我歌单接口](https://github.com/lyswhut/lx-music-desktop/blob/master/src/renderer/utils/musicSdk/kw/songList.js) 和 [酷狗歌单接口](https://github.com/lyswhut/lx-music-desktop/blob/master/src/renderer/utils/musicSdk/kg/songList.js) 的公开端点及字段，并进行了独立联网验证。

新版输出：`release/online-downloads`，不覆盖正在运行的旧版目录。
