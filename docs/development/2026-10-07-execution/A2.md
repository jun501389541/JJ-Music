## 实际改动

- 只有当前播放代次收到 AudioEngine `playing`，且当前曲目 ID 与已加载 ID 一致时，才确认播放并记录最近播放。
- 同一代次只确认一次；确认后将原始在线条目加入默认收集箱。本地条目不收集，换源候选不另建条目。
- 旧播放代次因现有代次守卫而不能收集；解析未完成或失败不会提前写入收集箱。
- 收集持久化失败显示错误提示，不中断已经开始的音频。
