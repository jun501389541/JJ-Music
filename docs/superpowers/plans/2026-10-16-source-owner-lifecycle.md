# 受限音源宿主的应用退出检测

范围：修复 OR8 UI 探针暴露的应用主进程强制退出后遗留受限宿主问题。保留现有工作，不执行真实音源，不修改日常配置，不提交或发布。

1. 用生产打包的 SourceRuntimeHost 和 source-host，加一个零网络生成源复现；先确认回归失败。
2. 父进程写入真正的 ownerPid，避免使用 runas 链中的 PPID。宿主在锁定 process API 前私有捕获原生探测和退出入口，每秒只发信号 0 检测。仅 ESRCH 才退出；权限错误、事件循环卡顿、时钟变化不作为死亡依据。不向脚本开放额外 API。
3. 复测父进程卡顿时保活、强制结束后自退，以及 Electron 生产入口和 Windows 受限令牌路径；运行完整离线门禁并记录证据。

边界：该检测依赖宿主事件循环；卡死脚本由既有父进程超时处理。PID 极快重用可能延迟自退，但不会向重用 PID 发终止信号。异常退出后的 scratch 目录仍由外部清理；本改动不让音源宿主递归删除目录，也不引入任意旧目录清扫。
