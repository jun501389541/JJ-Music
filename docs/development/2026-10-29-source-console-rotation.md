# 音源控制台日志轮换

基线：已发布v0.7.0后的main `ec65b63`。用户授权继续开发；本轮仅在`codex/source-log-rotation`修复已知日志限制，不提交、推送或发布，不读取真实脚本或个人曲库。

## 问题与修复

0.7.0给文件IPC增加1MiB日志读取上限，但宿主仍一直追加console.log。正常音源长期运行、累计输出超过上限后也被停止。合成原生宿主回归已复现，失败为`SourceFileLimitError`，不是网络或真实音源问题。

宿主按UTF-8字节计数，将当前日志控制在256KiB内；到达预算时以完整临时文件原子替换，首行为内部代次标记。主进程保存代次和字符游标，新代次从正文开头读，避免新文件比旧游标更长时漏掉开头；标记不进入用户日志。旧无标记文件保持兼容。单行输出另有8192字符保护，常规console格式化仍沿用2000字符限制。

主进程的1MiB读取上限与单音源失败回收不变。直接伪造超大通信文件仍被拒绝；轮换只限制正常宿主输出。轮换会丢弃较旧的磁盘日志，主进程仍只保留既有200行；不承诺保留每条高速输出日志，不扩大为磁盘配额或CPU隔离。
