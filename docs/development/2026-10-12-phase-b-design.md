## 目标

所有在线播放入口按目标音质统一解析，换源不改变原歌曲身份，不自动选择不同录音版本；旧请求实际取消，等待有限，显示实际解析来源和音质依据。阶段 A 原有单曲、队列、收集与失败停留规则继续验收。

## 推荐策略

| 项目 | 推荐值或行为 | 取舍 |
| --- | --- | --- |
| 档位顺序 | flac24bit → flac → 320k → 128k，从用户目标开始向下 | 不向上请求；各平台本档均失败才降档 |
| 平台顺序 | 原平台先；其他已启用、可解析的平台按 tx、wy、kw、kg、mg 固定顺序 | 顺序稳定，不根据一次偶然耗时重排 |
| 同平台音源顺序 | 复用现有 providersFor 的用户启用优先顺序 | 不新增排序设置；每个档位内轮询兼容音源 |
| 绑定源和私有参数 | 带 providerId 的条目只能交给对应实例；带 providerData 的条目不能把私有数据发送给未知实例 | 绑定失效给重新匹配提示，禁止静默解除绑定；跨平台候选使用自身资料，不复制原曲私有参数 |
| 无绑定的普通平台条目 | 使用兼容 LX 路径及平台标准 meta | 保留老歌曲可播放性 |
| 跨平台搜索 | 用歌名和歌手搜索第一页，每平台最多检查前 20 条、最多保留 3 个高置信度候选 | 不无限分页，不自动人工选曲 |
| 版本匹配 | NFKC、大小写/标点规范化，合作歌手按已知分隔符拆分并比较集合；版本标签必须一致；时长都有效且差 ≤ 5 秒 | 缺歌名、歌手、有效时长或明确版本证据冲突则不自动换曲；歌手名中的普通 & 不随意拆分 |
| 版本标签 | 区分 Live/现场、伴奏/Instrumental、翻唱/Cover、Remix、Demo、Acoustic、Remaster、语言及明确的特别版后缀 | 不为成功率跨版本替换；专辑可辅助排序，专辑不同不单独证明不同录音 |
| 总解析预算 | 60 秒，包含匹配、音源请求和回退 | 替换当前 15 秒 Promise.race；超时实际取消，慢音源不会无限占用播放器 |
| 单次音源请求 | 沿用已有 20 秒上限，并受总预算和播放取消信号限制 | 避免擅自缩短 LX 兼容请求时间 |
| 限流 | 明确可识别的 429 最多重试一次、等待 500ms，计入总预算；普通失败换候选，不重复无限尝试 | 无法识别的脚本错误不猜测为限流 |
| 播放地址失效 | 沿用一次 URL 重新解析，失效地址先移出缓存；最终失败停留当前曲 | 取消/预算耗尽不额外启动第二轮完整预算 |
| 缓存 | TTL 5 分钟、最多 128 条；只复用成功档位等于本次目标的条目；源变化全部失效 | 低档缓存不能绕过目标档尝试；匹配资料和私有参数不同不能共享缓存 |
| 源变化与迟到结果 | 版本/启用/健康事件清缓存并使正在解析的旧结果失效 | 禁止旧任务在清理之后重新写回缓存 |
| 音质检测 | 本阶段不增加开播前额外音频下载探测；在线地址没有可信实测规格时明确显示“按 XX 档位解析，规格未检测” | 不把请求 FLAC 当作已验证无损；未来真实检测到不符时展示真实规格，不冒充已验证目标档 |

以上阈值是产品上的保守规则，不保证资料相同就是同一母带。真实音源兼容验证单独记录，不用模拟样本宣称真实成功率。

## 架构

1. 共享类型新增本次在线播放资源描述：原歌曲引用、实际平台/候选 ID、目标档位、成功档位、音源 ID/名字/版本、是否换源、规格检测状态。不改 OnlineMusicInfo.id、保存歌单或收集箱条目。
2. 提取纯录音匹配模块和独立在线解析编排模块。播放器只提交原条目、目标档、取消信号和可控传输函数；编排模块统一控制档位外循环、候选内循环及预算。
3. music.url 的桥接参数增加可选严格模式和可取消请求 ID，使用现有 cancellableRequest 管理生命周期；PlaybackRouter 和 SourceEngine 传递 AbortSignal。宿主在外部取消或单次超时后通过 IPC/文件发送内部取消消息，子进程按请求上下文中止 lx.request 和提供的 fetch/XHR 网络通道；不更改 LX 脚本的请求载荷。下载现有显式严格请求不被在线播放调度代替。
4. 播放器用 AbortController 取消旧播放解析和停止操作；播放代次继续防止不可取消的旧结果覆盖状态。原条目继续作为队列、歌词、封面、历史和收集依据。
5. 缓存含原条目匹配资料、目标档和源状态代次；只在当前请求、当前源代次有效时写入。旧格式歌曲不重写、不迁移。
6. 播放页和迷你播放器展示实际资源平台、音源与请求档位；未测编码/码率/采样率/位深保留 unknown，不使用本地歌曲标签或输出设备采样率伪造在线资源规格。

## 验收样本

- 原平台只有低档、其他平台有目标档：选其他平台目标档，原条目和收集身份不变。
- 所有平台目标档失败：下一档重新从原平台开始；不高于用户目标。
- Live、伴奏、翻唱、Remix、同名异曲不自动替换；歌手顺序/已知分隔符/全角标点差异可匹配。
- 缺少有效时长、资料冲突、绑定失效或不可共享私有参数时，明确失败而非猜测。
- 快速切歌、停止和总预算超时取消底层请求；迟到结果不改变歌曲、资源详情、缓存或收集。
- 低档结果再次播放仍先试目标档；源重启/停用/升级、资料变化和过期 URL 不复用旧地址。
- 限流重试有限且计入预算；总预算耗尽不触发新一轮 60 秒解析。
- 旧歌单与 LastSession 恢复后仍引用原歌曲；来源显示和“未检测”文案准确。
